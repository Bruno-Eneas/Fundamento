FUNDAMENTO — PROJETO COM HISTÓRICO GIT

1. Extraia o ZIP inteiro para uma pasta nova. Não rode dentro do ZIP.
2. Abra Iniciar_Windows.bat (Python 3.12 necessário).
3. Para geração: instale Ollama, baixe qwen2.5:3b e abra Iniciar_Com_Ollama.bat.
4. Use a Local URL do terminal, não uma aba antiga em outra porta.
5. Testar_Windows.bat executa a suíte depois de instalar o ambiente.
6. Leia README.md, docs/Enunciado.pdf e docs/Matriz_requisitos.md.

O pacote inclui código, testes, modelo demonstrativo e histórico .git.
Não inclui .venv, modelo Ollama, CSV original, credenciais ou banco pessoal.
O arquivo Fundamento.bundle permite restaurar o histórico com Git instalado.
O prompt da pasta docs serve para uma conversa comum e não exige Work Mode.

Preserve sua instalação antiga como backup. Não substitua apenas app.py:
esta versão usa src/session.py, src/charts.py e assets/theme.css novos.
