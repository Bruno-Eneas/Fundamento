# Registro de uso de IA

Ferramenta: ChatGPT/Codex. Projeto iniciado em sessão de 16/11/2026; revisão técnica e organização Git em 20/11/2026.

A assistência incluiu planejamento, código, perfis fictícios, recuperação documental, interface, testes e documentação. Nesta revisão: correção do estado de geração, escolha explícita do feedback, testes com HTTP simulado, extração de CSS e gráfico, formatação, iniciadores, automação preparada e documentação.

Os dados de treinamento não foram gerados pela IA; casos da interface são fictícios. Não houve novo treinamento nesta revisão. As métricas pertencem ao artefato anterior. O grupo deve conferir rótulo, licenças, semântica das fontes e compreensão do código.

16 testes locais passaram; não houve nova geração Ollama ao vivo, revisão clínica, publicação ou avaliação externa. Geração no computador de Daniel foi observada anteriormente em capturas. As limitações dos testes estão em Verificacoes.md.

Os commits de revisão usam autoria técnica Assistente do projeto e data real desta execução. Modificações e revisão humana posteriores devem ser registradas pelo grupo conforme ocorrerem. Não declarar entrevistas, validação profissional ou aprovação visual que não aconteceram.

## Complemento de 20/11/2026: mudança de escopo laboratorial

A assistência também ajudou a organizar a interface de exames, regras determinísticas SBD/ADA/NIDDK, leitura conservadora de PDF textual fictício, testes, revisão de documentos acadêmicos e material de apresentação. O sistema não utiliza o gerador Ollama para produzir a interpretação laboratorial; o módulo gerativo anterior foi mantido como experiência histórica opcional. As saídas clínicas não foram validadas por médico, o código completo não foi executado em Streamlit neste ambiente e nenhum percentual individual de probabilidade foi fornecido. Os materiais escritos e apresentação exigem conferência do grupo antes da entrega.
